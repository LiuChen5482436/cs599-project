# 腹痛诊疗指南

## 腹痛位置与可能病因
1. **右上腹**：肝脏、胆囊疾病
2. **左上腹**：胃、胰腺疾病
3. **右下腹**：阑尾炎（转移性右下腹痛）
4. **脐周**：肠道疾病

## 腹痛性质
- **阵发性绞痛**：梗阻性疾病
- **持续性胀痛**：炎症性疾病
- **刀割样剧痛**：穿孔性疾病
- **隐痛**：慢性疾病

## 伴随症状评估
- 恶心呕吐
- 腹泻或便秘
- 发热
- 黄疸
- 呕血或黑便

## 就医建议
- 剧烈腹痛
- 腹痛伴发热
- 腹痛伴呕血或黑便
- 腹痛持续不缓解
- 儿童或老年人腹痛

## 居家护理
- 暂时禁食
- 观察腹痛变化
- 记录呕吐物和大便性状
- 避免自行服用止痛药

## 红旗症状
⚠️ 出现以下情况需立即就医：
- 剧烈刀割样腹痛
- 呕血或大量吐血
- 黑便或血便
- 发热伴腹痛
- 腹痛后意识模糊
- 腹壁硬如木板
