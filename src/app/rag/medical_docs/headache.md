# 头痛诊疗指南

## 头痛类型
1. **原发性头痛**：偏头痛、紧张性头痛、丛集性头痛
2. **继发性头痛**：由其他疾病引起

## 常见原因
- 偏头痛
- 紧张性头痛
- 感冒或流感
- 高血压
- 眼部疾病
- 颈椎病

## 头痛特征评估
- 部位（单侧/双侧）
- 性质（胀痛/刺痛/跳痛）
- 持续时间
- 诱发因素
- 伴随症状

## 就医建议
- 首次出现的剧烈头痛
- 头痛进行性加重
- 头痛伴发热
- 头痛伴呕吐
- 头痛伴意识变化
- 50岁以上新发头痛

## 居家护理
- 适当休息
- 保持情绪稳定
- 避免强光和噪音
- 必要时服用止痛药
- 记录头痛规律

## 红旗症状
⚠️ 出现以下情况需立即就医：
- 剧烈雷击样头痛
- 头痛伴意识模糊
- 头痛伴肢体麻木或言语不清
- 头痛伴发热和颈强直
- 头痛伴视物模糊
- 外伤后头痛
